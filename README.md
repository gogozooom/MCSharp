# SETUP

1. Download a zip file from the [releases](https://github.com/gogozooom/MCSharp/releases/) and extract it.
2. Download Minecraft Java version 1.21.10, rename the .jar to a .zip, and extract that.
3. Create a new folder next to MCSharp.exe named "Data" and move the contents from the 1.21.10 into the "Data" folder
4. Open the .exe file and play around!
